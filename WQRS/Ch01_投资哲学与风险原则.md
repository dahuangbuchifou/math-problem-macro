# 第一章：投资哲学与风险原则
> **版本**：V3.0（内容无变更，与V4.1总纲保持一致）

---

## 1.1 系统使命

WQRS（Waner Quant Research System）并非自动交易系统，而是一套以风险控制为核心、以量化研究为工具、以资产增值为目标的投资决策框架。

系统目标并非预测市场，而是：

- 在不确定市场中识别高概率机会
- 在风险可控前提下配置资本
- 在长期周期内实现稳定复利增长

WQRS 认为：市场永远不可预测，但市场状态可以识别，风险可以管理，纪律可以执行。

因此 WQRS 不试图预测未来，只评估：
- 当前市场处于什么状态
- 哪些资产具有更高风险收益比
- 应该承担多少风险

## 1.2 投资哲学

### 哲学一：风险优先于收益

多数投资者关注"能赚多少钱"，WQRS 首先关注"最多会亏多少钱"。

> 保住本金是一切收益的前提。没有本金，就没有复利的土壤。

**实践原则**：
- 每笔交易先定义最大可接受亏损
- 仓位由风险金额决定，而非资金比例
- 止损先于入场

### 哲学二：概率思维，而非预测思维

市场不可预测，但结果有概率分布。WQRS 通过提高胜率和盈亏比，在长期博弈中积累优势。

**核心公式**：
```
期望值 = 胜率 × 平均盈利 - 败率 × 平均亏损 > 0
```

单次交易的输赢不重要，重要的是在足够多次交易后，期望值为正。

### 哲学三：趋势跟随，而非逆势抄底

WQRS 不预测底部，不抢反弹，只在趋势确认后顺势入场。

**原则**：
- 不与市场方向对抗
- 突破确认后入场，而非提前埋伏
- 宁可错过，不可做错

### 哲学四：系统纪律，消灭人性弱点

人性在亏损时恐惧、在盈利时贪婪，这是散户长期亏损的根本原因。WQRS 通过系统化规则消除主观情绪干扰。

**纪律清单**：
- 止损必须在入场前设定，且必须执行
- 盈利目标通过移动止盈实现，不提前主观离场
- 加仓只在浮盈状态下进行，绝不补仓摊平亏损

### 哲学五：不交易原则

以下情况，系统强制不交易：

| 场景 | 原因 |
|------|------|
| 宏观状态为 Panic | 市场结构破坏，无效信号激增 |
| 宏观状态为 Capitulation | 个股禁止配置，仅允许宽基ETF观察仓 |
| 个股未通过 Hard Filter | 财务风险未排除 |
| 信号质量评分 < 70 | 胜率不足，期望值为负 |
| 白名单状态为 watchlist_suspended | 行业退出联动，暂停新信号 |

## 1.3 风险管理三大原则

### 原则一：1% 风险上限

每笔交易的最大亏损不超过总资产的 1%。

```
风险金额 R = 总资产 × 1%
仓位股数 = R ÷ (入场价 - 止损价)
```

这意味着：即使连续亏损 20 次，本金损失也不超过 18%，系统仍有充足弹药。

### 原则二：盈亏比门槛

所有交易的最低盈亏比要求（按宏观状态分层）：

| 宏观状态 | 最低 R/R 要求 |
|----------|--------------|
| Risk On（趋势突破） | ≥ 2.0 |
| Euphoria（高位） | ≥ 3.0 |
| Capitulation（逆向仓） | ≥ 4.0 |

R/R 不足的交易，无论信号多强，一律放弃。

### 原则三：绝不补仓摊平

亏损仓位绝对禁止补仓。加仓只在以下条件全部满足时进行：
- 持仓处于浮盈状态
- 价格在 VWAP 上方
- 动态均价止损成立
- 风险重算通过（单股/行业/系统三项均合规）

## 1.4 系统绝对生存红线

以下为系统层面的硬性约束，任何情况下不得违反：

| 红线 | 数值 |
|------|------|
| 单笔最大风险 | 总资产 1% |
| 单股最大暴露 | 总资产 10% |
| 单行业最大暴露 | 总资产 30% |
| 未脱险总敞口 | 总资产 5% |
| 凯利系数范围 | [0.1, 1.0] |
| 最大重试次数 | 3次 |

## 1.5 本章与整体系统的关系

本章是 WQRS 的**价值观基础层**。

所有后续章节的规则设计，包括宏观状态机的状态定义、仓位管理的风险预算模型、信号引擎的过滤逻辑，都以本章哲学为最终裁判标准。

当系统规则与市场直觉发生冲突时，**系统规则优先**。

> 执行纪律的能力，比任何技术分析技能都更重要。
