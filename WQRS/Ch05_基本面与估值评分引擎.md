# 第五章：基本面与估值评分引擎（Fundamental & Valuation Engine）
> **版本**：V4.1 | **修订内容（F04）**：新增行业退出联动机制——Ch04输出`dropped_sectors`时，本章自动将对应行业白名单股票状态置为`watchlist_suspended`，Ch06对该状态股票禁止新信号生成。

---

## 5.1 设计目标

### 5.1.1 本章定位

- Ch02：识别市场宏观状态
- Ch03：确定风险预算与资产配置比例
- Ch04：确定最具配置价值的行业方向
- **Ch05：在优势行业中筛选真正值得持有的公司**

本章不负责择时，只回答：**买什么？**

而 Ch06 信号引擎负责回答：**什么时候买？什么时候卖？**

### 5.1.2 核心原则

WQRS 不追求最便宜的股票，也不追求增长最快的股票，而是寻找：

> 质量优秀、估值合理、风险可控、具备持续经营能力的公司

优先级链：
```
风险控制 > 质量评估 > 估值评估 > 排序
```

---

## 5.2 总体架构

```
Sector Rotation Engine（Ch04）
    ↓
Candidate Universe（行业内个股池）
    ↓
Hard Filter（财务排雷）
    ↓
Accounting Red Flag（财务异常识别）
    ↓
Quality Score（企业质量评分）
    ↓
Valuation Score（估值评分）
    ↓
Fundamental Score（综合评分）
    ↓
Final Rank（最终排序）
    ↓
Candidate Pool（候选池）→ 输出至 Ch06
```

### 输入

来自 Ch04：Top 3 Sectors、Sector Score、Regime State、**dropped_sectors**（V4.1新增）

来自 Ch03：Risk Budget、Container Type

### 输出

Candidate Pool，包含：Ticker、Company Name、Quality Score、Valuation Score、Fundamental Score、Risk Flags、**Candidate Status**（V4.1新增：`active` / `watchlist_suspended`）

---

## 5.3 Hard Filter（财务排雷层）

Hard Filter 不是寻找优秀公司，而是**先排除明显危险公司**，避免后续评分失真。

| 排除条件 | 说明 |
|----------|------|
| 连续亏损 | 近3年累计净利润 ≤ 0，直接淘汰 |
| ST风险 | ST、*ST、退市整理，直接淘汰 |
| 财务杠杆过高 | 资产负债率 > 80%（金融行业除外），直接淘汰 |
| 流动性不足 | 近60日平均成交额 < 5000万元，直接淘汰 |

输出：`Pass` / `Reject`

---

## 5.4 Accounting Red Flag Engine

**目标**：识别潜在财务异常。

注意：异常 ≠ 造假，因此不直接淘汰，而是进入 `Fraud Review Queue` 等待人工复核。

| 规则 | 触发条件 |
|------|----------|
| 存贷双高 | 货币资金 > 有息负债，且货币资金/总资产 > 30% |
| 应收账款异常 | 应收账款增长率 > 营收增长率×2，持续两个报告期 |
| 现金流背离 | 净利润增长>0，同时经营现金流增长<0，持续两个报告期 |
| 商誉风险 | 商誉 > 净资产30% |

命中任意规则 → 进入 `Fraud Review Queue` 并附加 `Risk Flag`，复核前禁止进入白名单。

---

## 5.5 Quality Score（企业质量评分）

```
Quality Score = 40% × Profitability
              + 30% × Financial Health
              + 30% × Business Durability
```

总分：0～100

### Profitability（盈利能力）
- ROE Percentile（40%）
- ROIC Percentile（40%）
- Net Margin Percentile（20%）

### Financial Health（财务健康度）
- 经营现金流（40%）
- 资产负债率（30%）
- 利息覆盖倍数（30%）

### Business Durability（经营持续性）

设计目的：防止周期高点企业获得虚高评分。

- 近5年ROE波动率（40%）
- 近5年毛利率波动率（30%）
- 营业收入行业排名变化（30%）

---

## 5.6 Valuation Score（估值评分）

**设计原则**：估值用于**避免高估**，而非寻找最低估。

```
Valuation Score = 50% × Relative Valuation
                + 30% × Historical Valuation
                + 20% × Cashflow Yield
```

- **Relative Valuation**：行业内PE/PB/EV-EBITDA分位比较
- **Historical Valuation**：公司近5年PE/PB历史分位
- **Cashflow Yield**：FCF Yield（自由现金流收益率）

---

## 5.7 Fundamental Score

```
Fundamental Score = 70% × Quality Score
                  + 30% × Valuation Score
```

企业质量优先于估值。

---

## 5.8 Container Ranking Logic

### A容器（权益增长池）

```
Final Stock Rank = 30% × Sector Score + 70% × Fundamental Score
```

### B容器（高股息压舱石）

```
Final Stock Rank = 100% × Fundamental Score
```

不受行业轮动约束。

### C容器（商品与通胀对冲）

适用：黄金、能源、有色、商品ETF

优先使用 ETF 评分体系，不使用企业质量评分。

### D容器（现金）

不参与排序。

## 5.9 Candidate Tier System

| 等级 | 分数范围 | 说明 |
|------|---------|------|
| Tier 1 | ≥ 90 | 核心持仓候选 |
| Tier 2 | 80 ~ 89 | 观察名单 |
| Tier 3 | 70 ~ 79 | 备选名单 |
| 剔除 | < 70 | 不进入候选池 |

---

## 5.10 白名单生命周期（White List Lifecycle）

**自动复核触发**：

| 触发类型 | 条件 |
|----------|------|
| 季报更新 | 每季度财报发布后自动复核 |
| 年报更新 | 年报发布后全量复核 |
| 监管事件 | 立案调查、财务重述、重大处罚 |
| 生命周期到期 | Whitelist TTL = 365天，超期自动重评 |

### 行业退出联动降级机制（V4.1新增，F04）

**触发条件**：Ch04 输出 `dropped_sectors` 包含某行业时

**执行动作**：
1. Ch05 接收 `dropped_sectors` 字段
2. 将该行业内所有状态为 `active` 的白名单股票，自动降级为 `watchlist_suspended`
3. 降级操作不清除股票的评分数据，仅暂停信号生成资格
4. 已有存量仓位**不强制清仓**，由 Ch06 的 Exit Matrix 按正常止损逻辑处理

**恢复条件**：该行业在后续评估中重新进入 Ch04 Top 3，且股票评分仍达到 Tier 1/2，则自动恢复为 `active` 状态。

**状态定义**：

| 状态 | 含义 | Ch06 响应 |
|------|------|----------|
| `active` | 正常白名单 | 允许新信号生成 |
| `watchlist_suspended` | 行业退出临时暂停 | 禁止新开仓信号，存量仓位正常止损 |
| `fraud_review` | 财务异常待复核 | 禁止所有新信号 |
| `expired` | TTL到期待重评 | 禁止所有新信号 |

```json
{
  "candidate_pool": [
    {
      "ticker": "600519",

      "sector": "食品饮料",
```

## 5.12 职责边界

```
第五章负责：What To Buy（选股）
第六章负责：When To Buy / When To Sell（择时）
```

**严格禁止**：Signal Engine 绕过 Fundamental Engine 直接选股。Candidate Pool 为 Ch06 唯一合法股票来源。

---

## 5.13 本章总结

Fundamental & Valuation Engine 是 WQRS 的第二道风险防线，通过：

```
Hard Filter → Accounting Red Flag → Quality Score
→ Valuation Score → Fundamental Score → Tier Ranking → 行业退出联动
```

逐层过滤噪音与风险，最终形成**高质量、可解释、可复核、可量化**的 Candidate Pool。

至此，WQRS 完成：宏观判断 → 风险预算 → 行业选择 → 公司选择 四层决策框架。
